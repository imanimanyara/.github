> Default community health files for this account's personal repositories.

The profile README lives in
[`imanimanyara/imanimanyara`](https://github.com/imanimanyara/imanimanyara) —

the default `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, and
